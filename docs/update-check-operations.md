# 新版本检查：外联、状态文件与卸载说明

本说明供 v1.1.0 发布 A 段整理进 README 和发布说明。本段不修改安装器。

启用 Web 认证的 Server 默认在启动后随机延迟 1–10 分钟检查一次，之后每 12 小时向 `api.github.com` 发出 HTTPS 请求，读取固定仓库的最新正式版本号。失败会退避重试；页面只读缓存，不因刷新而访问 GitHub。请求不带 Server 版本、地址、实例标识、Cookie 或凭据。面板 ⚙ 的“新版本检查”开关可以关闭后续请求和版本提示。未启用 Web 认证的 Server 不启动检查器。

`update-check.json` 由 Server 在实际数据库同目录创建；默认安装位置为 `/var/lib/404-probe/update-check.json`，由 Server 用户所有，权限为 0600。文件保存开关、最近成功版本号和查询时间，不含敏感凭据。升级保留该文件；它不属于数据库备份/回滚副本。

当前安装器卸载只删除明确登记的托管文件，会将 `update-check.json` 当作“未识别文件”保留。因此状态目录非空，服务账户也会保留。若需要完全清理，在 Server 已卸载/停止后手动删除这个文件，再重新运行对应正式版的官方卸载入口，让安装器按现有规则清理空状态目录和服务账户。其他未识别文件也必须先由用户确认处理；不要为删除更新检查缓存而删除数据库或整个状态目录。仅删除 JSON 文件本身不会自动删除目录或账户。

下一版计划把该文件加入卸载清单，届时需要安装器夹具测试。本版继续沿用现有安装器规则。
