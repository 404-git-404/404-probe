- 内存、磁盘容量和 Swap 继续使用 1024 进位的 KiB/MiB/GiB。
- 网络入站/出站累计、本周期用量、套餐流量额度、详情和历史图表中的网络流量统一按原始 bytes 使用 1000 进位 B/KB/MB/GB/TB；网络字节速率使用 B/s、KB/s、MB/s。
- 带宽继续使用 Mbps/Gbps 比特单位；磁盘 I/O 暂沿机器指标现状，不全局替换格式化函数。
- 不能只改单位标签，也不能静默缩放已有套餐额度的实际 bytes。累计基线、套餐周期和真实用量比例语义保持不变。
