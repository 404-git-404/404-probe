撤销 Agent

撤销只会让面板不再接收这台机器的数据。要在机器上彻底卸载，请在那台机器上运行：sudo 404-probe-install uninstall agent。运行卸载命令时需确认删除机器上的托管数据。

撤销后不能恢复原身份。历史记录、计划和任务会保留。
